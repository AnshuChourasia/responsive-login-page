# 🔐 Responsive Login Page

A modern and responsive **Login Page UI** built using **HTML**, **CSS**, and **JavaScript**. This project was created to practice designing authentication interfaces with a clean layout, responsive design, and user-friendly experience.

## 🚀 Live Demo

👉 https://anshuchourasia.github.io/login-page/

## ✨ Features

- 🔐 Modern login interface
- 📱 Fully responsive design
- 🎨 Clean and minimal UI
- ✍️ Styled input fields and buttons
- 📩 Contact section
- ⚡ Smooth navigation and layout
- 🌐 Cross-browser compatible

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
